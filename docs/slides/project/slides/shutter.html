Q5 · 셔터 상태

식각 중과 식각 안 할 때는 사실상 다른 상태다

센서 값 차이

1.4~2.0배

셔터 1(식각 중)과 셔터 0의 차이가 표준편차의 1.4~2.0배다. "큰 차이" 기준 0.8을 크게 넘는다. 냉각 압력도 1.50배 다르다.

고장 구분력

0.154 → 0.209

냉각 압력의 |AUC−0.5|가 전체 구간보다 셔터 1 구간만 쓸 때 더 크다. 섞으면 고장 신호가 공정 상태 차이에 묻힌다.

→ 선행 연구처럼 셔터 1(식각 중) 구간만 분석·모델링에 쓴다.

셔터는 이온 빔과 웨이퍼 사이의 가림막입니다. 공식 설명은 없지만 선행 연구는 1을 식각 중으로 봅니다.
